# Exercism Solutions

This repository contains my completed solutions for various programming tracks on Exercism.

## Repository Structure

Each track is managed via isolated branches synchronized directly from Exercism. When an exercise is completed, a new branch and Pull Request are generated. Once merged, the code becomes available on the default branch.

## How it Works

1. Solutions are submitted locally or via the Exercism online editor.
2. The Exercism GitHub Syncer automatically pushes the iteration to a track-specific branch.
3. A Pull Request is opened to merge the exercise into the main branch.
4. After merging, the solution file structure is preserved within the track directory.
